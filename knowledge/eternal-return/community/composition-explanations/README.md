현재 결과 데이터에는 아이템 획득 시각과 실제 교전 상대 로그가 없다. 따라서 파워 스파이크를 `초반·중반·후반`으로 단정하거나 특정 적 실험체를 카운터로 표시하지 않는다.

## 실험체·무기 특성을 반영한 인게임 플랜

역할만 같은 조합이 동일한 설명으로 수렴하지 않도록 각 멤버에 다음 파생 축을 붙인다.

| 축          | 값                                                     | 설명                                     |
| ----------- | ------------------------------------------------------ | ---------------------------------------- |
| 전열 위치   | 전열·중열·후열                                         | 교전 시작 전 기본적으로 서야 하는 위치   |
| 유효 사거리 | 근거리·중거리·장거리                                   | 주요 위협을 반복해서 행사할 수 있는 거리 |
| 전술 성향   | 진입·후속 돌진·보호·포킹·폭딜·지속전·지역 장악 등      | 스킬셋의 대표적인 교전 기능              |
| 교전 임무   | 개시·후속 진입·전열 유지·주 화력·견제·제어·보호·마무리 | 해당 3인 조합 안에서 맡을 우선 임무      |

동일 실험체도 무기에 따라 전술 성향이 크게 바뀌는 경우 `캐릭터_무기` 단위 오버라이드를 사용한다. 예를 들어 양손검 유키는 진입 후 순간 화력, 쌍검 유키는 추격형 지속 교전으로 분리하며, 도끼 마커스는 진입 후 전열 유지, 망치 마커스는 제어와 진입 차단 비중을 더 높게 본다.

포킹 담당을 고를 때는 위 유효 사거리를 상대 점수로 사용한다. 장거리끼리도 차이가 명확한 캐릭터·무기는 별도 압박 사거리 보정을 두며, 주 화력 담당은 지속 화력과 원거리 딜러 역할을 우선한다. 예를 들어 아야와 이바가 함께 있는 포킹 조합에서는 이바가 선제 견제, 아야가 주 화력을 맡도록 분리한다. 세 번째 담당은 마무리로 고정하지 않고 지역 장악·보호·제어·제거 화력을 비교한다. 헨리가 포함된 3원딜 조합에서는 상대의 접근 경로와 진입 타이밍을 제한하는 진입 억제를 우선한다.

생성기는 조합을 하나의 고정 유형으로 압축하지 않는다. 화력 전달 방식, 목표 접근 방식, 핵심 화력의 보호 의존도, 전열 구조, 원하는 교전 길이, 기본 타깃 규칙의 여섯 축을 먼저 계산한다. 화면에서는 이를 특성 배지로 보여주고, `승리 조건 → 싸움 시작 → 첫 타깃 → 전열 행동 → 화력 행동 → 전환 조건 → 망하는 패턴`의 일곱 원칙을 붙인다. 이어서 세 실험체 각각에 `우선 임무 + 실행 행동 + 금지 행동`을 배정한다.

이 원칙은 실제 리플레이에서 관찰한 고정 콤보가 아니라 역할·무기·전술 태그를 합성한 휴리스틱이다. 따라서 특정 스킬 순서를 단정하지 않고, 현재 세 명의 화력이 겹치는 상태와 교전을 멈춰야 할 조건을 설명한다. 상세 근거와 규칙은 [`combat-doctrine`](../combat-doctrine/README.md)에 기록한다.

## 승률과 역할 설명을 결합하는 법

역할 구조가 좋아 보여도 실제 조합 지표가 낮을 수 있고, 구조상 약점이 있어도 숙련자 표본에서 높은 성과를 낼 수 있다. 화면에서는 다음을 동시에 보여준다.

1. 실제 승률, 평균 RP, 평균 순위와 게임 수
2. 후보군 백분위로 만든 운영 성향과 신뢰도
3. 세 실험체·무기의 복수 역할, 전열 위치와 유효 사거리
4. 여섯 교전 특성, 일곱 교전 원칙과 세 실험체별 담당
5. 힘이 모이는 **조건**
6. 유리할 수 있는 상대 구조와 주의할 상대 구조
7. 5~6번은 직접 로그가 없는 가설이라는 경고

## 전수 검증 결과

2026-08-09에 DB의 117개 캐릭터·무기 멤버로 만들 수 있는 서로 다른 실험체 3인 조합 256,010개를 확장 생성기에 통과시켰다.

- 미분류 역할: 0개
- 빈 전술 성향·전열 위치·유효 사거리: 0개
- 빈 교전 구조·6개 교전 특성·7개 교전 원칙·3개 실험체 담당: 0개
- 117개 캐릭터·무기 능력 벡터의 10개 기능 점수 누락: 0개
- 교전 순서에 같은 멤버가 중복 배정된 조합: 0개
- 모든 1차 역할 조합 `7 × 7 × 7 = 343`가지 단위 테스트
- 한국어·영어·일본어·중국어 간체·번체 설명 스칼라 키 221개 일치

256,010개는 현재 DB에 실제 존재하는 약 218,222개보다 넓은 가능한 멤버 조합 집합이다.

## 유지보수

1. `COMBO_ROLES`가 바뀌면 117개 현재 멤버의 미분류 여부를 다시 검사한다.
2. 패치별 조합 테이블이 생기면 설명에 `patchVersion`과 티어 범위를 노출한다.
3. 아이템·레벨 이벤트가 수집되면 역할 기반 파워 스파이크를 시간 데이터로 교체한다.
4. 직접 교전 상대가 수집되면 역할 상성 가설과 실제 적 조합 성과를 분리 표시한다.
5. 시즌 12 무기 스킬 개편이 반영된 역할 검수가 끝날 때까지 실험체별 상성 문장은 확정 표현을 쓰지 않는다.
