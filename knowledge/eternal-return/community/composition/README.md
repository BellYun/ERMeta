[S 조합 전술 설명 마흔네 번째 묶음](validations/2026-10-15-s-narrative-batch-44/README.md)은 남은 새 S 조합 2,725개 전부의 1차 판단 초안(2,359개 제안·366개 보류), 고정쌍 8,175개 비교, 근소한 음수 원시 RP 사례 4개를 기록했다.

[S 조합 보류 834개 경향](validations/2026-10-15-s-held-tendencies/README.md)은 보류 집단의 전체 기간 통합 성적, 설명 규칙의 빈틈, 스킬별 반례와 우선 재검토 대상을 정리했다.

옛 `제어·지원` 보류 36개를 [무기 기준으로 재확인](validations/2026-10-15-s-held-tendencies/README.md#옛-제어지원-보류-36개를-무기로-다시-확인)한 결과 원거리 무기 3인 25개와 근접 무기 포함 11개였다. 아디나·헤이즈·바냐는 바냐의 옛 `전사` 주석과 달리 원거리 3인 구도이며, 36개 전체나 하트 후보를 뺀 31개를 하나의 제어·지원 유형으로 취급하지 않는다.

같은 옛 보류 묶음의 [나타폰·제니·마이와 나타폰·띠아·마이](validations/2026-10-15-s-held-tendencies/README.md#옛-제어지원-보류-36개를-무기로-다시-확인)는 마이 1선과 두 원딜/스증 화력의 **쌍포 조합**으로 수정했다. 마이 포함 8개 중 원거리 무기 2명과 짝을 이룬 6개에 띠아 방망이의 스증 화력 사례 1개를 더해 **7개**가 이 구도다. 무기 분류만으로 띠아를 제외하지 않는다.

사용자 교정에 따라 [클로에 + 원딜/스증 딜러 2명](validations/2026-10-15-s-held-tendencies/README.md#클로에와-딜러-둘의-1선-교정)은 클로에·니나가 1선을 만드는 구도로 먼저 검토한다. 기존 `세 명 모두 사격` 보류 94개 중 해당 조합 11개는 일부 사례일 뿐이며, 개별 조합의 교전 설명은 별도로 검토한다.

클로에를 제외한 [83개 정확한 조합](validations/2026-10-15-s-held-tendencies/three-shooters-roster.md#그-밖의-83개)은 사용자 선택에 따라 경향 분석에서 `3원딜 편성`으로 묶는다. 유형 이름을 조합별 승리 이유나 개별 교전 설명 완료로 취급하지 않는다.

[하트 + 원딜/스증 딜러 2명과 엠마의 별도 구도](validations/2026-10-15-s-held-tendencies/README.md#하트와-딜러-둘의-세이브-및-엠마-별도-구도)도 사용자 교정으로 기록했다. 하트·프리야·유스티나는 옛 `제어·지원` 보류에 속하지만 하트의 궁극기 세이브가 중심인 사례다. 원딜과 스증 딜러가 섞인 두 동료도 이 구도에 포함한다. 엠마의 변이·위치 이동은 옛 `첫 충돌 담당 없음` 사유만으로 평가하지 않는다. 하트 포함 보류 34개와 엠마 사유 89개 전체를 같은 교전 방식으로 일반화하지 않는다.

[탱커 포함 근접 전열 보류 조합 재검토](validations/2026-10-15-s-held-tank-frontline-reviews/README.md)는 옛 탱커 주석이 붙은 181개 정확한 조합을 모두 개별 검토했다. 조건부 교전 설명 147개와 설명 보류 34개를 기록했으며, [추가 167개 검토 본문](validations/2026-10-15-s-held-tank-frontline-reviews/individual-reviews.md)에는 각 조합의 스킬 연결 조건과 비교 반례가 있다.

## 확인된 공략 항목

### 1. `1탱·1근·1원`은 별도로 검토할 조합 사례다

탱커 운영 강의는 `1탱·1근·1원` 구성을 “조합을 짤 때 중요한 점”으로 별도 챕터화한다. 이어서 탱커의 포지션 기준, 교전 디테일과 싸우기 전 시뮬레이션을 각각 다룬다.

이번 조사에서는 해당 영상의 상세 스크립트를 확보하지 못했으므로 이 구성이 좋다거나 나쁘다고 단정하지 않는다. 챕터 제목만으로 보존할 수 있는 범위는 이 구성을 중요한 검토 대상으로 삼았다는 점까지다.

근거: [조합 챕터 1:15~](https://www.youtube.com/watch?v=oK1WI8xr5zI&t=75s)

### 2. 탱커 선택과 실제 포지션은 함께 봐야 한다

같은 영상은 조합 구성 다음에 탱커의 포지션 기준과 교전 디테일을 배치한다. 따라서 ERMeta에서 “탱커 포함 여부”만으로 조합을 설명하기보다, 전열이 어디에 서고 어떤 교전을 시작하는지까지 별도 분석 축으로 볼 가치가 있다.

구체적인 포지션 규칙은 아직 구조화하지 않았으므로 현재 단계에서는 분석 가설로만 사용한다.

근거: [탱커 포지션 2:22~](https://www.youtube.com/watch?v=oK1WI8xr5zI&t=142s), [탱커 교전 8:15~](https://www.youtube.com/watch?v=oK1WI8xr5zI&t=495s)

### 3. 조합의 유효 사거리 차이가 교전 구도를 바꾼다

시즌 11 운영 영상은 사거리가 긴 조합과 짧은 조합이 만났을 때의 교전 구도를 별도 챕터로 설명한다. 이는 캐릭터 이름 세 개만 보는 조합 통계에 다음 맥락이 추가로 필요하다는 근거가 된다.

- 먼저 피해를 줄 수 있는 거리
- 먼저 진입해야 하는 팀
- 전열과 후열 사이의 거리
- 교전 시작 전 양 팀의 위치

이 네 항목은 영상 챕터를 ERMeta 분석 질문으로 변환한 `종합`이며, 원저자가 제시한 고정 분류표가 아니다.

근거: [팔이 긴 조합과 짧은 조합 10:07~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=607s)

### 4. 싸우기 전에 조합별 교전을 시뮬레이션한다

탱커 강의는 실제 교전 디테일 뒤에 “싸우기 전 시뮬레이션”을 별도 항목으로 둔다. 조합 추천을 만들 때도 정적인 역할표보다 예상 교전 순서를 설명할 수 있어야 한다는 분석 가설로 연결한다.

근거: [교전 전 시뮬레이션 16:50~](https://www.youtube.com/watch?v=oK1WI8xr5zI&t=1010s)

## ERMeta가 보존할 종합 원칙

> 아래 내용은 확인된 챕터를 ERMeta 관점에서 재구성한 `종합`이다.

1. 탱커·근딜·원딜의 개수만으로 조합을 좋거나 나쁘다고 확정하지 않는다.
2. 조합의 전열 위치와 유효 사거리를 별도 특성으로 본다.
3. 교전을 시작해야 하는 팀과 받아쳐야 하는 팀을 구분한다.
4. 조합 설명은 “누가 먼저 들어가고, 누가 어떤 거리에서 딜하는가”를 포함해야 한다.
5. 특정 역할 구조에 대한 평가는 같은 패치·티어의 실제 3인 조합 통계로 검증한다.

## 데이터 분석에 연결하기

3인 조합 통계에 역할 분류를 추가한다면 다음 파생 특성을 버전과 함께 관리할 수 있다.

| 파생 특성              | 분석 질문                                                 |
| ---------------------- | --------------------------------------------------------- |
| `frontlineCount`       | 먼저 사거리 안으로 들어가 공간을 만드는 인원이 몇 명인가? |
| `meleeThreatCount`     | 근거리에서 실질적인 딜 위협을 만드는 인원이 몇 명인가?    |
| `rangedThreatCount`    | 전열 뒤나 먼 거리에서 압박할 수 있는 인원이 몇 명인가?    |
| `effectiveRangeClass`  | 조합 전체의 유효 사거리를 어떤 기준으로 분류할 것인가?    |
| `engageResponsibility` | 먼저 교전을 열어야 하는 실험체와 조건은 무엇인가?         |
| `formationType`        | 전열·후열의 위치 관계를 어떤 유형으로 설명할 수 있는가?   |

이 값들은 공식 API가 직접 제공하는 필드가 아니다. 실험체 스킬, 무기, 빌드와 교전 방식을 근거로 한 별도 역할 분류가 필요하다.

### 검증 방법

1. 실험체·무기·핵심 특성별 역할과 유효 사거리 분류 버전을 만든다.
2. 같은 패치와 티어 버킷 안에서 조합을 역할·사거리 구조별로 묶는다.
3. 표본 수, 평균 RP, 평균 순위, Top3 비율과 승률을 함께 비교한다.
4. 특정 고숙련 유저와 소표본 조합이 결과를 끌어올린 것은 아닌지 확인한다.
5. 통계로 검증되지 않은 커뮤니티 평가는 제품의 확정 설명으로 사용하지 않는다.

## 아직 검증하지 않은 질문

- `1탱·1근·1원`에서 문제가 생기는 정확한 조건과 예외는 무엇인가?
- 탱커의 포지션을 데이터로 표현할 수 있는가?
- 팔이 긴 조합과 짧은 조합의 경계는 실험체별 사거리만으로 정할 수 있는가?
- 포킹, 돌진, 받아치기와 지속전 조합을 어떤 규칙으로 분류할 것인가?
- 솔로 큐와 고정 팀의 조합 성과 차이를 분리할 수 있는가?

## 패치 의존성과 갱신 조건

- 실험체 사거리, 이동기 또는 탱커의 교전 구조가 크게 바뀌면 재검증
- 새 실험체나 빌드가 기존 역할 경계를 흔들면 역할 분류 버전 갱신
- 같은 주제의 최신 공략이 나오면 기존 주장을 덮어쓰지 않고 조건과 예외를 비교
