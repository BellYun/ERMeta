# S 조합 네 번째 100개 개별 교전 가설 검토

2026년 10월 23일, [앞선 100개 묶음](../2026-10-23-full-fight-201-300/README.md)에 이어 판수순 미검토 S 조합 100개를 다시 읽었다. [작업 목록](queue.json)에 순서와 정확한 키를 고정하고 [검토 완료 목록](../../../../../../frontend/data/composition-explanations/full-fight-reviewed-2026-10-23-batch-301-400.json)에 이 100개를 추가했다. 설명은 모두 사용자 확인 전 `assistant-proposed` 교전 가설이다.

각 조합의 **세 명이 함께 만드는 강점**을 첫 문장에 쓰고, 공식 한국어 스킬 원문과 같은 두 명을 고정한 동료 교체 사례를 대조했다. 정확한 무기까지 포함한 세 고정쌍씩 총 300개 맥락에 연결된 교체 후보 성과 방향은 33,022건이다. 이 방향 집계는 자동 계산된 관찰 자료이며, 33,022개의 전술을 하나씩 검증했다는 뜻은 아니다. 본문에서 명시한 공식 스킬 출처는 314건이다.

이번 묶음에서는 레온의 `물길(Q)` 자체를 군중 제어로 설명하지 않고 `물보라(W)` 보호막을 구분했다. 실비아의 일반형 아군 회복은 `스피드건(Q)`으로 기록했다. 하트 공연과 나타폰 촬영은 피해를 넣을 시점에 제약이 있으므로, 근접 진입이나 설치 피해가 그동안 마무리를 낼 것처럼 쓰지 않았다. 비형 방망이는 1선 탱커로 읽고 `신명나게 놀아보자!(R)`의 피해 감소와 추가 체력을 확인했다. 이슈트반의 `양자 얽힘(W)`은 이동 제어가 아니라 적중 시 보호막으로 바로잡았다.
