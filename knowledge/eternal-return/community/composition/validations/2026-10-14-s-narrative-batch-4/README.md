## 이번 묶음에서 드러난 판단 지점

- **전선이 딜러의 유효 거리와 겹치는가.** 카티야의 장거리 사격과 재키의 추격은 거리가 다르다. 알론소가 로지의 가까운 권총 거리 앞에 남아야 테오도르의 뒤쪽 화력·회복과 하나의 교전이 된다.
