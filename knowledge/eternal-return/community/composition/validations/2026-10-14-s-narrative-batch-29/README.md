## 이번 묶음에서 구분한 조건

- 버니스 저격총은 무기명보다 다수 탄환의 실제 적중 거리가 중요하다. 테오도르 광선은 충전·각도와 아군 통과 경로를, 르노어 파동은 긴 견제와 주변 속박의 다른 거리를 구분했다.
- 니아의 블록은 싱크 포인트로 이동하고 처형에는 저장 피해량 조건이 필요하다. 혜진 공포는 같은 대상에 스킬 세 번 적중, 샬럿 무적은 지연 발동, 피올로 올려치기는 사슬묶기 적중 뒤 활성화된다. 하트 공연에서는 적도 죽지 않고, 바냐 수면과 엘레나 빙결은 공격받으면 깨진다.
- 90개 고정쌍 중 87개에는 승률·평균 순위·팀 평균 원시 RP가 모두 더 좋은 교체 사례를 반례로 연결했다. 아이솔 돌격 소총·혜진·비형의 아이솔+비형, 유키 쌍검·키아라·테오도르의 유키+키아라, 리오·아르다·헨리의 리오+헨리 고정쌍은 그런 교체 사례가 없어 지표가 엇갈리는 비교를 연결했다. 이는 동료 교체의 인과 효과를 증명하지 않는다.
