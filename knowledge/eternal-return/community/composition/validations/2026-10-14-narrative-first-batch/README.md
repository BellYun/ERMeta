# 정확한 3인 조합 설명: 첫 배치

## 자료와 판정 범위

2026-10-03 18:05 KST 기준 사전집계의 실험체·무기 일치 조합 237,561개를 사용했다. 2026-10-12에 추출한 화면 S 목록은 **11,015개**다. 이번 일곱 조합은 그중 **0.064%를 살펴본 초기 사례**일 뿐이며 S 전체의 설명을 대표하지 않는다. S 목록의 판수 구간은 10~29판 9,502개, 30~99판 1,478개, 100판 이상 35개다. **S 등급은 후보를 찾는 데만 사용**했다. 각 조합은 세 명 중 두 명을 고정한 세 맥락에서 모든 세 번째 후보를 확인했다. 시즌·패치·티어·판수로 비교 행을 제거하지 않았다.

아래 수치는 전 기간 통합 `승/판 · 평균 순위 · 원시 팀 평균 RP`다. RP는 `total_rp / total_games`이며, 화면 S 카드에 표시되던 3분의 1 값이 아니다. RP의 정의가 12.4 전후로 달라져 이 값을 전 기간의 실제 순 획득량으로 해석하지 않는다. 교전 장면과 상대 조합은 없으므로 스킬 원문으로 가능한 행동을 확인한 뒤, **설명문은 교전 가설**로 썼다. 사용자가 교전 구도를 확인한 아이솔 사례만 사용자 검토로 표기했다.

### 유형 평균이 정확한 조합과 어긋나는 곳

옛 유형 DB의 `스킬딜러+원거리 딜러`에 `탱커 · 진입 보호`를 더한 915개 맥락은 다른 세 번째 후보 대비 멤버 전체 평균을 감안한 승률 차이 −0.69%p, 순위 이점 −0.038, RP 차이 +0.13이다. 하지만 **아이솔·아드리아나·에스텔**은 같은 두 명의 레녹스·가넷 후보보다 세 지표가 앞선다. `탱커 · 선봉 보호`의 3,180개 맥락도 승률 −0.44%p, 순위 −0.019, RP +0.59로 방향이 섞였지만, **로지·이바·일레븐**은 레녹스·알론소·에스텔 후보보다 세 지표가 앞선다. 유형 이름만으로 카드 문장을 만드는 방식은 이 두 정확한 조합을 놓친다.

현우·비앙카·블레어는 셋이 `전사`로 표시된다는 이유로 전부 근접 돌진형이라고 설명할 수 없다. 비앙카의 창·마법진은 위치를 잡는 방식이고, 블레어는 형태 전환 뒤 반복 공격과 회복을 사용한다. 아야·하트·헨리 역시 옛 분류에서 `원거리 딜러+스킬딜러+스킬딜러`지만, 이 경우의 핵심 질문은 조합 명칭보다 **첫 진입을 누가 어떻게 막을지**다. 이는 스킬 원문으로 구성한 교전 가설이며 통계로 확인된 장면은 아니다.

## 이번 배치에서 고정할 품질 기준

1. 카드용 문장은 세 명이 **어느 거리에서 무엇을 보장하는지**와 **어떻게 깨지는지**가 읽혀야 한다. 스킬 세 개를 차례대로 쓰는 설명만으로는 부족하다.
2. 정확한 조합 성적과 고정쌍 대안은 설명을 점검하는 자료다. 승률 차이만으로 특정 스킬이 승리 원인이라고 쓰지 않는다.
3. 옛 유형의 평균과 정확한 조합이 충돌하면 유형을 지우거나 억지로 맞추지 않고, 왜 이 세 명의 예외가 생길 수 있는지 따로 서술한다.
4. 보류 사례도 남긴다. S 표시가 있어도 기계적 상호작용이나 사용 순서의 핵심이 확인되지 않으면 자신감 있는 카드 설명으로 내보내지 않는다.

`node scripts/audit-composition-narratives.mjs`로 여섯 서술의 정확한 조합 키, 스킬 원문 키, 두 명 고정 비교 키, 유형 집계 출처 연결을 확인했다. 이 감사는 스킬 적중이나 교전 순서를 검증하지 않는다.
