# S 조합 전술 설명 두 번째 묶음

전체 기간 통합 사전집계(`pooled-all-trios-2026-10-13.ndjson.gz`, 2026-10-03 18:05 KST)에서 화면 S로 표시된 **정확한 실험체·무기 조합 5개**를 추가로 읽었다. 세 명 중 두 명을 고정한 모든 동료 교체를 확인하고, 저장된 한국어 스킬 문구로 가능한 교전 구도를 서술했다. 시즌·패치·티어·판수로 비교 후보를 제외하지 않았다. 기존 유형 이름은 탐색 단서로만 사용했다.

작성한 5개 문단은 모두 [개별 설명 파일](../../../../../../frontend/data/composition-explanations/narratives.v2.json)에 `assistant-proposed`로 저장했다. 이 작업으로 문단 설명은 **7개에서 12개**로 늘었다. 사용자가 교전 해석을 직접 확인한 설명은 여전히 1개다.

## 단순 규칙으로 굳히지 않은 이유

- **전열의 위치가 핵심일 수 있다.** 니키·에스텔·이렘이 포함된 세 사례는 모두 뒤의 원거리 화력이 실제로 닿는 위치에서 첫 충돌을 맡아야 설명이 성립한다. 같은 역할 이름만으로 이런 위치 관계를 알 수는 없다.
- **고정 지점의 피해 조건은 다르다.** 바바라는 센트리건 유지 거리, 이바는 방출에 필요한 바이탈 포스와 방향이라는 별개의 제약이 있다. 에스텔이 있다고 해서 둘이 자동으로 같은 적을 오래 공격했다는 뜻은 아니다.
- **제어기는 충돌할 수 있다.** 유민의 강화된 밀어내기는 에이든·피올로가 때리는 지점에서 적을 빼낼 수도 있다. 이 사례를 무조건적인 군중 제어 연계로 쓰지 않았다.
- **더 좋은 동료 교체 사례도 있다.** 자히르·에스텔·카티야보다 자히르·카티야+쇼우는 11/33승, 평균 순위 3.21, 평균 RP 33.82로 세 지표가 앞섰다. 에이든·피올로·유민보다 에이든·피올로+미르카도 6/18승, 평균 순위 3.39, 평균 RP 49.09로 앞섰다. 이들을 작은 판수라며 목록에서 지우지 않았고, 두 제안의 배타적인 우위 근거로 쓰지 않았다.

각 문단의 스킬 원문 키, 비교 조합 키, 성립 조건, 실패 조건, 관찰 불가 항목은 설명 파일에 연결했다. [초안 출처 감사](../../../../../../frontend/scripts/audit-s-composition-reasoning-drafts.mjs)는 5개 모두 정확한 조합·스킬·동료 교체 키에 연결됨을 확인했고, [서술문 감사](../../../../../../frontend/scripts/audit-composition-narratives.mjs)는 전체 12개 문단의 출처 연결을 확인했다. 두 검사는 실제 교전의 참·거짓을 판정하지 않는다.
