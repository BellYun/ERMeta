# S 조합 열한 번째 100개 개별 교전 가설 검토

2026년 10월 23일, [앞선 100개 묶음](../2026-10-23-full-fight-901-1000/README.md)에 이어 판수순 미검토 S 조합 100개를 다시 읽었다. [작업 목록](queue.json)에 순서와 정확한 키를 고정하고 [검토 완료 목록](../../../../../../frontend/data/composition-explanations/full-fight-reviewed-2026-10-23-batch-1001-1100.json)에 이 100개를 추가했다. 설명은 모두 사용자 확인 전 `assistant-proposed` 교전 가설이다.

각 조합의 **세 명이 함께 만드는 강점**을 첫 문장에 쓰고, 공식 한국어 스킬 원문과 같은 두 명을 고정한 동료 교체 사례를 대조했다. 정확한 무기까지 포함한 세 고정쌍씩 총 300개 맥락에 연결된 교체 후보 성과 방향은 33,107건이다. 이 방향 집계는 자동 계산된 관찰 자료이며, 33,107개의 전술을 하나씩 검증했다는 뜻은 아니다. 본문에서 명시한 공식 스킬 출처는 330건이다.

이번 묶음에서는 레온의 `물길(Q)`을 제어기로 오인하지 않고 `잠영(E)`의 띄우기를 썼다. 나타폰의 `셔터 찬스(R)` 촬영 중 무적과 마르티나의 취재 중 촬영을 구분했다. 프리야의 보호막은 꽃이 핀 뒤 `포르타멘토(W)`를 꽃에 맞혀야 한다는 점을 반영했다. 하트의 `Peacemaker(R)` 공연 중에는 적도 처치할 수 없다는 제약을 설명했다.
