## 대량 서술의 다음 단계

생성기를 연결할 때는 기존 사용자 확인 문장을 덮어쓰지 않고, 미검토 10,915개를 정확한 조합별로 처리한다. 결과는 `proposed`와 `held`를 나누어 저장한다. 출처 감사에 통과한 `proposed`도 별도의 전술 검토를 거치기 전에는 추천 카드의 확정 근거가 아니다. 특히 사용자 교정 사례, 유형 평균과 정확한 조합 성적이 엇갈린 사례, 수면·무적처럼 스킬 순서가 충돌하는 사례를 먼저 평가해야 한다.

현재 셸에는 `OPENAI_API_KEY`나 `ANTHROPIC_API_KEY`가 지정되어 있지 않다. 로컬 Codex CLI는 발견했지만 대량 호출에 사용하지 않았다. 따라서 전수 **설명문 생성은 실행하지 않았다**. 생성 모델과 호출 예산을 정하면 이미 만든 입력·검사 체계에 연결할 수 있다.
