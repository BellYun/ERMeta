# S 조합 100개 개별 교전 가설 검토

2026년 10월 23일 기준, 판수 상위의 미검토 S 조합 100개를 20개씩 다섯 묶음으로 다시 읽었다. [작업 목록](queue.json)의 100개 키만 [검토 완료 목록](../../../../../../frontend/data/composition-explanations/full-fight-reviewed-2026-10-23-batch-100.json)에 추가했다. 기존 설명이 있던 조합도 새 기준으로 다시 검토했으며, 전부 `assistant-proposed`다. 사용자 확인이나 경기 장면 검증을 뜻하지 않는다.

## 검토 자료와 판단 기준

- 각 조합의 정확한 실험체·무기, 전체 기간 통합 승률·평균 순위·원시 팀 평균 RP를 확인했다.
- 세 고정쌍별로 세 번째 동료를 바꾼 후보 전체의 성과 방향을 집계하고, 설명에 쓴 교체 후보의 역할 차이를 읽었다. 100개 조합에 고정쌍 300개, 후보별 성과 방향 33,107건이 연결된다. 이 숫자는 자동 집계된 대조 자료의 규모이며, 33,107경우의 전술을 각각 검증했다는 뜻은 아니다.
- 공식 한국어 스킬 문구와 연결된 스킬 인용 254건을 대조했다. 스킬 설명과 통합 성적은 가능한 교전 구도를 뒷받침하지만, 실제 교전 순서나 인과관계를 입증하지 않는다.
- 설명의 첫 문장에 세 명이 함께 얻는 강점을 놓고, 1선·CC·주력딜·서브딜이 어떻게 이어지는지, 동료를 교체하면 무엇이 달라지는지, 어떤 조건에서 구도가 깨지는지 적었다.

검토 중 키아라의 사슬 속박은 `집착(E)`으로 바로잡았다. 나타폰의 `타임 랩스(W)` 제어와 `셔터 찬스(R)` 무적을 구분했다. 비형·마커스가 1선을 맡는 조합에서는 탱커를 후속 딜러처럼 서술하지 않도록 고쳤다. `자히르·알론소·유민`처럼 비교 지표가 엇갈리는 경우에는 동료 교체보다 전반적으로 낫다는 주장을 피했다.
