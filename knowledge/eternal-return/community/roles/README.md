## 결론

ERMeta의 현재 6개 역할 라벨은 검색과 표시에는 유용하지만, 실제 조합 설명에는 충분하지 않다.

```text
탱커 · 전사 · 암살자 · 스킬딜러 · 원거리 딜러 · 지원가
```

이 분류는 공식 포지션 체계가 아니라 ERMeta 내부 매핑이다. 한 실험체·무기 조합이 여러 역할을 가질 수 있으며, 같은 실험체도 조합과 성장 상태에 따라 전열 유지와 진입 임무가 달라질 수 있다.

## 역할을 나누는 세 층

| 층 | 묻는 질문 | 예시 값 |
| --- | --- | --- |
| 기본 역할 | 팀에서 무엇을 제공하는가? | 전열, 지속 딜, 순간 폭딜, 제어, 보호, 회복 |
| 교전 성향 | 어떤 방식으로 싸움을 여는가? | 선진입, 받아치기, 포킹, 측면 진입, 추격, 이탈 |
| 조건 | 언제 그 역할을 잘 수행하는가? | 사거리 확보, 좁은 지형, 아군 연계, 핵심 아이템, 스킬 준비 |

`원거리 딜러` 같은 명칭은 공격 거리만 설명하고, 선공권·자기보호·딜이 나오는 시간은 설명하지 못한다. 조합 지식에서는 다음 축을 함께 저장한다.

| 축 | 기록할 내용 |
| --- | --- |
| `formation` | 전열·중열·후열 중 주 위치 |
| `effectiveRange` | 실제 위협이 유지되는 짧음·중간·김 |
| `engageMode` | 선진입·후속진입·받아치기·포킹 |
| `damagePattern` | 순간 폭딜·지속 딜·누적 포킹 |
| `targetAccess` | 후열 접근, 전열 처리, 단일 점사 능력 |
| `control` | 하드 CC, 둔화·구역 통제, 방해 능력 |
| `peel` | 아군에게 붙은 적을 떼어내는 능력 |
| `mobility` | 진입·이탈·추격 수단과 실패 위험 |
| `durability` | 집중 공격을 버티는 정도와 조건 |
| `executionLoad` | 조작, 명중, 거리·쿨타임 판단 부담 |

## 확인된 자료와 해석

### 포지션 추천 영상

하이도 영상은 포지션별 입문 실험체를 추천하지만, 마지막 챕터에서 쉬운 실험체보다 자신이 마음에 드는 실험체를 고르는 것도 중요하다고 명시한다. 따라서 이 자료는 영구 티어표가 아니라 **입문 후보를 좁히는 분류 자료**로 사용한다.

공개 댓글에는 다음과 같은 사용자 관찰이 있었다. 댓글은 사실 확정 근거가 아니므로 모두 `검증 필요`다.

- 이전 MOBA에서 맡았던 포지션과 유사한 역할부터 시작하면 적응에 도움이 될 수 있다.
- 마커스는 조작 구조가 단순하다는 의견과 별개로, 조합에 따라 탱커와 브루저 사이에서 임무가 달라지고 동작 선후딜·판정·집중 공격 대응이 난점이라는 의견이 있다.
- 이슈트반은 초중반이 강하고 후반 영향력이 낮아진다는 의견이 있다. 이는 실험체 역할이 시간대와 함께 바뀔 수 있다는 파워 커브 가설이다.

댓글 작성자의 실력대, 표본과 적용 패치가 확인되지 않았으므로 제품 문구나 추천 규칙으로 바로 사용하지 않는다.

### ERMeta 내부 역할 매핑

[`characterMap.ts`](../../../../frontend/src/lib/characterMap.ts)의 `COMBO_ROLES`는 실험체·무기 조합에 하나 이상의 역할을 붙인다. 이는 조합 설명 UI를 위한 편집 지식이며 공식 분류가 아니다.

[`characterJobGroups.ts`](../../../../frontend/const/characterJobGroups.ts)는 순환식으로 임시 역할을 할당하는 placeholder다. 파일 주석대로 공식·커뮤니티 매핑으로 교체되기 전에는 지식 원본이나 분석 근거로 사용하지 않는다.

## 저장 형식

```yaml
character_role_profile:
  character: "실험체 이름"
  weapon: "무기군"
  patch: "12.0"
  labels: ["전사", "탱커"]
  axes:
    formation: "전열"
    effectiveRange: "짧음"
    engageMode: ["선진입", "받아치기"]
    damagePattern: "지속 딜"
    targetAccess: "중간"
    control: "높음"
    peel: "중간"
    mobility: "조건부"
    durability: "조건부 높음"
    executionLoad: "중간"
  conditions:
    strong_when: []
    weak_when: []
  evidence:
    - type: "공식 | 통계 | 영상 | 사용자 제보"
      url: "원본 URL"
      status: "확인됨 | 종합 | 검증 필요"
  reviewed_at: "YYYY-MM-DD"
```

## 12.0 재검증 대기열

1. `COMBO_ROLES`의 모든 실험체·무기 조합을 현재 캐릭터 목록과 대조한다.
2. 무기 스킬 개편으로 진입, 생존, 보호 방식이 달라진 조합을 우선 재분류한다.
3. 역할 라벨과 축별 프로필을 분리해, 라벨은 검색에 쓰고 축은 조합 설명에 쓴다.
4. 사용자 제보는 패치·티어·무기·대표 상황을 함께 받은 뒤 통계와 교차 검증한다.
