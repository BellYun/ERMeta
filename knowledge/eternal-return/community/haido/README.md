## 먼저 기억할 것

이 문서의 공략은 공식 규칙이나 모든 판의 정답이 아니다. 특히 야생 동물 위치, 오브젝트 생성 규칙, 지도별 기습 위치와 크레딧 소비 타이밍은 패치로 바뀔 수 있다. 현재 게임에 적용하기 전 원본 영상의 게시일과 최신 패치노트를 함께 확인한다.

**시즌 12 경고:** 2026-08-06의 12.0 패치에서 저장 루트·재료/레시피와 후반 임시 안전지대 구조가 바뀌었다. 아래 시즌 11의 지역·시간·아이템·임시 안전지대 지식은 운영 원칙만 유지하며, 현재 수치와 동선은 [12.0 공식 패치노트](https://playeternalreturn.com/posts/news/3742)로 재검증한다.

## 확인된 공략 항목

### 1. 페이즈가 바뀌기 전에 다음 행동을 정한다

2026년 솔랭 운영 영상은 게임을 다음 체크포인트로 나눈다.

| 페이즈        | 작성자가 챕터로 제시한 확인 항목      |
| ------------- | ------------------------------------- |

| 1일차 밤      | 변이 무리, 오브젝트 자리 잡기         |
| 2일차 낮      | 크레딧을 쓰는 돈 턴, 지역 파밍        |
| 2일차 밤      | 오브젝트, 자색 안개                   |
| 3일차 낮      | 두 번째 돈 턴, 시야 확보              |
| 3일차 밤      | 얻은 정보 활용, 지역 점거             |

### 2. 크레딧은 보유량보다 사용 타이밍이 중요하다

시즌 11 운영 영상은 2일차 낮 돈 턴 전에 교전을 피하고, 3일차 낮에 두 번째 돈 턴을 잡으며, 아직 크레딧을 쓰지 않았다면 소비를 우선하는 항목을 별도 챕터로 둔다. 기본 개념 영상도 낮마다 돈 턴을 사용하라고 정리한다.

- 2일차 낮: 돈 턴 전 불필요한 교전을 줄인다.
- 3일차 낮: 두 번째 소비 타이밍을 계획한다.
- 소비가 밀렸다면 다른 행동보다 장비 전환을 먼저 검토한다.

근거: [시즌 11 운영 3:38~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=218s), [기본 개념 5:54~](https://www.youtube.com/watch?v=HWuyLlkqTzY&t=354s)

### 3. 오브젝트를 못 먹어도 성장 행동까지 멈추면 안 된다

기본 개념 영상은 오브젝트와 동물을 모두 놓치는 상태를 성장에서 뒤처지는 원인으로 보고, 둘 중 하나는 확보하는 대안을 제시한다. 오브젝트에 갈 수 없을 때는 다른 고가치 지역이나 여러 야생 동물 무리를 선택하는 예시도 든다. 마지막에는 숙련도와 레벨을 별도 체크 항목으로 둔다.

이 지역 예시는 2026-04-20 지도와 생성 규칙에 묶인 **패치 의존 정보**다. 영구적으로 남길 원칙은 “경합이 불가능하면 안전한 대체 성장원을 고른다”까지다.

근거: [기본 개념 2:47~](https://www.youtube.com/watch?v=HWuyLlkqTzY&t=167s), [숙련도·레벨 6:35~](https://www.youtube.com/watch?v=HWuyLlkqTzY&t=395s)

### 4. 시야 도구는 목적에 따라 나눈다

기본 개념 영상은 카메라와 정찰 드론을 같은 용도로 보지 않는다.

- 카메라: 한 위치의 시야를 일정 시간 고정하는 용도
- 정찰 드론: 진입 전에 일시적으로 정보를 확인하는 용도

시즌 11 운영 영상도 후반에 시야 아이템과 캡슐의 선택을 별도 항목으로 다루며, 맵 정보 누락과 오브젝트 인원 확인을 주요 판단으로 제시한다.

근거: [기본 개념 4:53~](https://www.youtube.com/watch?v=HWuyLlkqTzY&t=293s), [시즌 11 운영 6:28~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=388s), [시야 아이템 11:48~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=708s)

### 5. 정보는 모으는 데서 끝나지 않고 다음 위치 선택에 써야 한다

가장 최근에 확인한 티어 상승 영상은 오브젝트에 모인 팀 수, 주변 오브젝트 부재, 지역 가치, 균열의 인원과 상대 위치를 판단 재료로 둔다. 4일차 낮에 뒤처진 팀은 상대 위치를 고려해 안전한 자리를 잡는 운영을 별도로 설명한다.

시즌 11 운영 영상도 오브젝트 여부로 남은 인원을 추정하고, 위클라인을 잡는 팀과 만났을 때의 대응, 후반 지역 정보와 시야를 챕터로 분리한다.

근거: [티어 상승 운영 5:27~](https://www.youtube.com/watch?v=vGhFQ4jkVpY&t=327s), [열세 팀 운영 16:47~](https://www.youtube.com/watch?v=vGhFQ4jkVpY&t=1007s), [시즌 11 운영 7:41~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=461s)

### 6. 후반에는 추격보다 지역과 교전 구도를 본다

시즌 11 운영 영상은 4일차 낮~밤 이후 적을 지나치게 오래 쫓지 않는 판단과, 사거리가 긴 조합과 짧은 조합이 만났을 때의 교전 구도를 각각 다룬다. 구체적인 진입·이탈 방법은 조합과 실험체에 따라 달라지므로 여기서는 다음 원칙만 보존한다.

- 후반 추격에는 지역을 빼앗기거나 다른 팀에 끼일 기회비용이 있다.
- 교전 전 양 팀의 유효 사거리 차이를 확인한다.
- 승산이 낮은 팀일수록 상대 위치가 확인된 안전한 지역을 우선한다.

근거: [후반 추격 9:35~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=575s), [조합별 교전 구도 10:07~](https://www.youtube.com/watch?v=Ao2ghmTqTTg&t=607s)

### 7. 지도별 기습 지점은 별도 패치 데이터다

기습 방지 영상은 골목길부터 연구소까지 루미아 섬의 지역을 순서대로 나누어 위험 지점을 설명한다. 이는 “지역 진입 전에 사각과 매복 지점을 확인한다”는 안정적인 원칙과 “어느 좌표가 위험한가”라는 패치 의존 데이터를 분리해야 하는 사례다.

현재 문서에는 좌표를 옮겨 적지 않는다. 지도 구조가 바뀐 뒤 낡은 위치를 안내할 위험이 있으므로, 필요할 때 [원본의 지역별 챕터](https://www.youtube.com/watch?v=cCqsmKNUuZ8&t=15s)와 현재 지도를 함께 검증한다.

## ERMeta 종합 운영 체크리스트

> 아래 순서는 여러 영상의 챕터를 ERMeta 관점에서 합친 `종합`이며, 하이도가 그대로 제시한 단일 체크리스트가 아니다.

이동 또는 교전 전에 다음을 확인한다.

1. 지금 페이즈에 예정된 성장·오브젝트·돈 턴이 무엇인가?
2. 아직 쓰지 않은 크레딧 때문에 장비 템포가 밀려 있지 않은가?
3. 오브젝트 경합이 어렵다면 안전한 동물·지역 파밍 대안이 있는가?
4. 오브젝트, 균열, 맵 표시로 확인되는 상대 팀 수와 위치는 어디인가?
5. 진입로의 시야는 고정할 것인가, 잠깐 확인할 것인가?
6. 우리 조합과 상대 조합의 유효 사거리·진입 구조는 어떤가?
7. 추격이나 순간이동의 목적과 다음 이득을 한 문장으로 설명할 수 있는가?
8. 뒤처진 상태라면 싸움보다 생존 가능한 지역 선점이 우선인가?

## 분석에 연결할 가설

공략을 ERMeta 데이터와 연결할 때는 다음을 검증 가능한 가설로 다룬다.

| 커뮤니티 공략에서 얻은 가설                      | 필요한 데이터                                      | 현재 한계                                    |
| ------------------------------------------------ | -------------------------------------------------- | -------------------------------------------- |
| 제때 크레딧을 소비한 팀이 중반 교전에 유리하다   | 시간대별 크레딧 보유·소비와 장비 완성 시각         | 현재 최종 경기 결과만으로 시점 복원이 어려움 |
| 오브젝트 실패 후 대체 성장을 한 팀은 덜 도태된다 | 시간대별 동물·오브젝트·레벨·숙련도 변화            | 이벤트 타임라인 데이터 필요                  |
| 시야와 정보 우위가 후반 순위를 안정시킨다        | 카메라·드론 사용, 지역 진입, 피격·사망 시점        | 공식 API 제공 여부 재확인 필요               |
| 사거리 차이가 조합의 교전 성과를 설명한다        | 실험체별 역할·사거리 분류와 조합별 패치 성과       | 역할 분류 버전과 표본 통제가 필요            |
| 열세 팀의 안전 지역 선점이 RP 손실을 줄인다      | 시간대별 팀 전투력, 지역 위치, 최종 순위와 RP 변화 | 위치 이력이 없으면 직접 검증 불가            |

이 가설은 높은 승률의 원인을 이미 설명한 결론이 아니다. 필요한 이벤트 데이터가 없으면 제품 문구에서 인과관계로 쓰지 않는다.
