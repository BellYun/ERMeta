## 이번 재학습의 결론

`포킹 조합`, `받아치기 조합`, `다각도 조합`처럼 조합당 하나의 구도명을 정하는 방식은 부족하다. 같은 원거리 딜러도 케어가 필요한 지속 화력형과 직접 인파이팅하는 유형이 다르고, 같은 스킬 딜러도 포킹형과 누킹형의 교전 시간이 다르며, 같은 브루저도 돌진형과 중간 지점을 지키는 유형의 임무가 다르다.

따라서 교전 설명은 **조합 유형을 먼저 고르는 분류 문제**가 아니라, 서로 독립적인 특성을 조립하는 문제로 다룬다.

## 교전법을 만드는 6개 특성 축

### 1. 화력 전달 방식

| 값            | 교전에서 필요한 조건                                    |
| ------------- | ------------------------------------------------------- |
| `poke`        | 본교전 전에 반복해서 사거리를 사용할 시간               |
| `burst`       | 제어·진입과 핵심 화력을 짧은 창에 겹칠 조건             |
| `sustained`   | 같은 대상을 계속 공격할 시야·거리·생존 시간             |
| `distributed` | 한 명의 핵심 딜러보다 여러 명이 각자 화력을 이어갈 조건 |

### 2. 목표 접근 방식

| 값              | 교전에서 필요한 조건                                         |
| --------------- | ------------------------------------------------------------ |
| `forcedEngage`  | 첫 진입 뒤 아군 후속 화력이 닿는 거리                        |
| `dive`          | 둘 이상의 진입각과 같은 목표에 도착하는 시간 동기화          |
| `counterEngage` | 상대가 이동기·진입기를 실제로 소모할 때까지 핵심 대응기 보존 |
| `frontToBack`   | 전열이 만든 공간 안에서 가장 가까운 위협을 계속 공격         |

### 3. 핵심 화력의 보호 의존도

| 값               | 교전에서 필요한 조건                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| `careRequired`   | 보호 담당이 공격보다 진입 차단을 우선하고 딜러의 공격 시간을 연장       |
| `infighting`     | 딜러도 중거리까지 전진할 수 있으므로 전열과 동시에 압박하되 고립은 방지 |
| `selfSufficient` | 별도 보호 자원을 덜 요구하므로 제어·진입에 더 많은 자원을 사용 가능     |
| `noSingleCarry`  | 한 명을 지키는 대신 세 명의 사거리와 쿨다운이 겹치는 구간을 유지        |

### 4. 전열 구조

| 값            | 교전에서 필요한 조건                                                  |
| ------------- | --------------------------------------------------------------------- |
| `soloFront`   | 혼자 버틸 수 있는 거리까지만 전진하고 후속 화력 범위를 벗어나지 않음  |
| `doubleFront` | 둘이 동시에 모든 생존기를 쓰지 않고 시선·피해·제어를 교대             |
| `noFront`     | 누군가 오래 맞는 교전을 피하고 사거리·이동기·제어 구간을 번갈아 사용  |
| `tripleMelee` | 각자 다른 목표와 싸우지 않고 한 지역의 공간을 좁혀 같은 대상부터 압축 |

**근접 전열에 탱커가 있는 경우(사용자 교정, 2026-10-15):** 탱커가 몸을 먼저 밀어 넣어 전면과 첫 충돌을 맡는 것을 기본 교전 가설로 둔다. 이것은 적 후열까지 무조건 돌진한다는 뜻이 아니다. 탱커가 만든 거리 안에서 다른 두 명이 같은 대상에 닿는지, 탱커가 물러날 때 누가 전선을 이어받는지, 제어 방향이 화력을 흩어놓지 않는지를 정확한 무기·스킬로 확인한다. 탱커가 없는 3근접과 같은 설명을 적용하지 않는다. 실제 진입 순서는 경기 장면이 없으므로 관찰 사실로 단정하지 않는다.

### 5. 원하는 교전 길이

| 값            | 교전에서 필요한 조건                                                  |
| ------------- | --------------------------------------------------------------------- |
| `shortWindow` | 첫 제어와 핵심 화력 실패 시 남은 스킬까지 순차적으로 버리지 않고 이탈 |
| `longCycle`   | 생존기·제어기·화력 쿨다운을 한 번에 쓰지 않고 다음 담당에게 턴을 넘김 |

### 6. 기본 타깃 규칙

| 값                 | 우선 기준                                                   |
| ------------------ | ----------------------------------------------------------- |
| `controlledTarget` | 첫 제어가 걸려 아군 화력이 실제로 닿는 대상                 |
| `nearestThreat`    | 아군 핵심 화력을 위협하며 전열을 넘어오는 가장 가까운 대상  |
| `exposedBackline`  | 보호·이탈 범위에서 벗어나 둘 이상의 진입이 동시에 닿는 후열 |
| `intrudingDiver`   | 이동기를 소모하고 아군 진형 안에 들어온 적                  |

타깃 규칙은 `적 원딜 우선`처럼 역할 이름으로 고정하지 않는다. 중요한 것은 **현재 세 명의 화력이 실제로 겹칠 수 있는가**, **그 대상이 우리 승리 조건을 직접 방해하는가**다.

## 조합 설명의 새 출력 형식

각 조합은 순서도가 아니라 다음 일곱 문장으로 설명한다.

1. `승리 조건`: 이 조합이 한타를 이기기 위해 반드시 유지해야 하는 상태
2. `싸움 시작 방식`: 먼저 열기, 상대 진입 받기, 체력 우위 만들기, 목표 고립 기다리기
3. `첫 타깃 규칙`: 누구라는 이름이 아니라 어떤 상태의 적을 먼저 보는지
4. `전열 행동`: 공간 생성, 시선 고정, 진입 차단, 어그로 교대 중 무엇을 맡는지
5. `화력 행동`: 포킹, 같은 대상 점사, 가까운 위협 지속 공격, 후속 진입 중 무엇을 맡는지
6. `전환 조건`: 목표를 바꾸거나 추격을 멈추는 조건
7. `망하는 패턴`: 이 조합이 가장 자주 깨질 수 있는 행동

분석 데이터에는 일곱 원칙을 모두 유지하지만 카드 UI에는 반복을 줄이기 위해 `승리 조건`, `싸움 시작`, `망하는 패턴`만 노출한다. 상단 특성 배지도 `화력 방식`, `접근 방식`, `전열 구조` 세 개만 보여 준다. 타깃·전열·화력·전환의 세부 판단은 실험체별 담당 문장에 반영한다.

일곱 문장 아래에는 세 실험체별 담당을 별도로 붙인다. 각 담당은 `주 담당`, `보조 기능`, `실행할 행동`, `하지 말아야 할 행동`으로 구성한다. 예를 들어 같은 이중 전열 조합에서도 개시 담당은 후속 화력 범위 안에서 첫 제어를 만들고 전열 유지를 보조하며, 주 화력 담당은 제어된 대상에 화력을 집중하면서 자신의 포킹이나 억제 기능도 함께 행사한다.

담당은 캐릭터의 일반적인 포지션을 반복하지 않는다. 해당 세 명 안에서 누가 먼저 행동하기 적합한지 점수화한 뒤 조합의 접근 방식·타깃 규칙·전열 구조를 결합해 문장을 선택한다. 공식 스킬 설명에서 반복 확인된 제어·유지 영역·투사체 억제·보호 신호는 별도 기능 점수로 비교한다. 따라서 같은 실험체도 다른 두 팀원에 따라 `교전 개시`, `후속 진입`, `전열 유지`, `주 화력`, `제어`, `진입 억제`, `보호`, `마무리`의 주·보조 담당 조합이 달라질 수 있다.

특히 포킹 조합을 `선제 견제·주 화력·마무리`로 고정하지 않는다. 선제 견제와 주 화력을 먼저 찾은 뒤 남은 실험체의 지역 장악·진입 차단이 강하면 `진입 억제`, 보호 기능이 강하면 `보호`, 제어 연계가 강하면 `제어`, 실제 제거 화력이 강할 때만 `마무리`를 배정한다. 아야·이바·헨리 3원딜에서는 이바가 선제 견제, 아야가 주 화력, 헨리가 상대 접근 경로와 진입 타이밍을 제한하는 진입 억제를 맡는다.

클로에 + 원딜 또는 스증 딜러 2명은 클로에·니나가 **1선을 만드는 구도**다(2026-10-16 사용자 교정). 원딜·스증이 한 명씩 섞인 경우도 포함한다. 니나를 앞에 배치해 상대 접근을 먼저 받고, 니나의 둔화·띄우기와 클로에·니나 링크의 피해 분담으로 두 딜러가 공격할 시간을 만드는지 검토한다. 이는 클로에 본체가 근접 탱커처럼 깊게 들어간다는 뜻이 아니다. 니나의 위치·소멸 여부, 링크 사용 시점, 두 동료의 유효 거리와 같은 대상에 공격이 닿는지를 조합별 조건으로 남긴다.

하트 + 원딜 또는 스증 딜러 2명은 **하트 궁극기의 세이브**가 핵심인 별도 구도다(2026-10-16 사용자 교정). 원딜·스증이 한 명씩 섞인 경우도 포함한다. 하트·프리야·유스티나에서는 프리야의 꽃 밀어내기·보호막·속박이 접근을 늦추고, 하트가 위험한 순간 공연으로 두 딜러를 살릴 수 있는지 검토한다. 공연은 범위 안 적에게도 사망 방지와 종료 후 회복을 적용하므로, 아군이 살아남은 뒤 공격을 다시 잇는 거리와 시점까지 확인한다. 하트가 낀 다른 3인에게 이 교전 설명을 복사하지 않는다.

아디나·헤이즈·바냐는 원거리 무기 3인 구도다(2026-10-16 사용자 교정). 바냐의 옛 `전사` 주석으로 3원딜 편성에서 제외하지 않는다. 아디나의 천체 스킬, 헤이즈의 총기별 사거리와 바냐의 나비 투사체·보호막·비행을 함께 보고, 바냐가 더 앞선 위치에서 접근을 받더라도 두 동료와 화력이 이어지는지를 검토한다. `세 원거리 무기`와 `세 명 모두 안전한 후열`은 같은 뜻이 아니다.

이렘 투척 + 근접 동료 둘에서는 이렘이 **스킬 딜러로 변수를 만든다**(2026-10-16 사용자 교정). 이렘은 고양이 형태로 전사처럼 플레이할 수도 있지만, 이 편성의 기본 교전 역할은 공 투척 피해·표식과 둔화·매혹이 두 근접 동료의 접근과 피해에 연결되는지 보는 것이다. 고양이 돌진·속박·띄우기는 조합에 따라 기회가 열렸을 때의 후속 수단으로 판단한다. 두 근접 동료 사이의 첫 충돌 담당과 이렘의 실제 스킬 적중 위치는 정확한 3인마다 확인한다.

비형 방망이는 **1선 탱커**로 본다(2026-10-16 사용자 교정). 비형이 몸을 밀어넣어 도발·보호막·피해 감소·추가 체력으로 첫 충돌을 받고, 나머지 두 명이 그 전선 안에서 공격을 잇는 구도를 기본으로 검토한다. 옛 `전사` 유형 주석으로 이 역할을 배제하지 않는다. 동료들도 진입할 수 있으므로 누가 먼저 제어를 맞히고 어느 표적을 함께 때리는지는 정확한 세 명의 스킬을 보고 서술한다.

요한·에키온·바냐는 **서폿 + 2전사의 유지력 조합**이다(2026-10-16 사용자 교정). 요한의 회복·보호막·궁극기 방어력 증가와 에키온·바냐의 자체 보호막이 교전을 이어갈 시간을 만드는지 본다. 에키온의 돌진·반복 피해와 바냐의 투사체·비행은 활동 거리가 다르므로, 요한의 지원 범위와 두 전사의 공격이 함께 유지되는 조건을 확인한다. 바냐는 아르카나를 쓰지만 이 정확한 조합에서의 전사 역할을 무기 거리로 부정하지 않는다. 아디나·헤이즈·바냐의 3원딜 해석과는 동료 맥락이 다르다.

나타폰·제니·마이는 **마이 1선 + 원거리 화력 둘**의 쌍포 조합이다(2026-10-16 사용자 교정). 마이가 피해 감소·보호막·도발로 첫 접근을 받고 나타폰과 제니가 그 뒤에서 공격 시간을 얻는지 본다. 마이 궁극기의 제압은 피해를 막지만 대상 아군의 행동도 잠시 멈추므로 세이브와 화력 재개의 시점이 중요하다. 이 사례를 마이가 낀 모든 조합으로 일반화하지 않는다.

나타폰·띠아·마이도 **마이 1선 + 원딜/스증 화력 둘**의 쌍포 조합이다(2026-10-16 사용자 교정). 띠아의 방망이는 근거리 무기지만, 이 조합의 띠아는 색 조합에 따른 스증 피해와 제어를 맡는다. 노란 물감 투척과 빨강·파랑 스킬의 거리 차이를 확인하고, 띠아를 항상 나타폰과 같은 위치의 후열로 고정하지 않는다. 무기 분류만으로 쌍포 여부를 판정하지 않는다.

엠마는 별도 위치 제어 사례로 본다(2026-10-15 사용자 교정). 토끼 변이는 이동을 완전히 막지는 않지만 대상의 다른 행동을 제한하고, 비둘기·모자·토끼로 향하는 궁극기의 이동에는 속박·당김·주변 변이 효과가 각각 붙는다. 엠마가 있으면 상대의 첫 접근을 어떤 위치에서 끊는지 살피되, 엠마를 자동으로 전열이나 일반 원딜로 분류하지 않는다.

`선제 견제` 담당은 포킹 태그만으로 정하지 않는다. 근거리·중거리·장거리의 기본 유효 사거리를 상대 점수로 환산하고, 역할 분류만으로 차이가 사라지는 장거리 스킬 딜러는 캐릭터·무기 단위 보정값을 사용한다. 반대로 `주 화력`은 지속 화력과 원거리 딜러 역할을 더 높게 평가한다. 이 값은 실제 게임 단위의 미터 수치가 아니라 조합 안에서 누가 먼저 사거리를 행사할지 정하기 위한 상대 우선순위다.

## 특성 조합별 교전 예시

### 케어 필요 지속 원딜 + 단독 전열 + 보호 기능

- 승리 조건: 원딜이 전열 뒤에서 같은 대상을 계속 공격할 시간을 확보한다.
- 시작 방식: 전열이 상대 첫 진입을 받거나 가까운 위협을 멈춘 뒤 싸움을 연다.
- 첫 타깃: 원딜 사거리 안에서 가장 가까우며 진형을 넘어오는 적.
- 전열 행동: 적 후열까지 깊게 쫓기보다 원딜과 적 진입자 사이를 유지한다.
- 보호 행동: 상대 진입기가 사용되기 전에 핵심 보호·밀쳐내기를 소모하지 않는다.
- 전환 조건: 가까운 위협이 이탈해 화력이 닿지 않으면 새로 들어오는 대상에게 즉시 전환한다.
- 망하는 패턴: 전열이 적 후열을 쫓는 동안 원딜과 보호 담당이 분리된다.

### 포킹 딜러 + 전열 + 지속 화력

- 승리 조건: 전열의 체력을 진입 비용으로 쓰기 전에 포킹으로 체력 또는 이동기 우위를 만든다.
- 시작 방식: 포킹 적중 후 적 이동기가 빠지거나, 전열 제어가 같은 대상에 닿을 때 본교전으로 전환한다.
- 첫 타깃: 포킹에 맞아 방어 자원이 줄었고 전열 제어가 이어질 수 있는 대상.
- 전열 행동: 포킹이 진행되는 동안 풀 진입하지 않고 상대가 딜러에게 바로 닿지 못하는 선만 유지한다.
- 화력 행동: 포킹 담당은 사거리 우위를 반복하고, 지속 화력은 들어오는 가장 가까운 적부터 처리한다.
- 전환 조건: 포킹 담당의 핵심 스킬이 빗나가고 적 진입기가 남아 있으면 본교전을 보류한다.
- 망하는 패턴: 체력 우위가 생기기 전에 전열 혼자 들어가 포킹과 지속 화력이 서로 다른 대상을 본다.

### 누킹·점사 + 강제 진입 + 후속 돌진

- 승리 조건: 세 명의 핵심 화력을 한 대상의 방어·이탈 수단보다 짧은 시간에 겹친다.
- 시작 방식: 첫 제어 적중 또는 핵심 이탈기 소진을 신호로 지정한다.
- 첫 타깃: 역할과 무관하게 첫 제어 뒤 두 후속 화력이 모두 닿는 대상.
- 전열 행동: 첫 행동으로 시선을 고정하되, 목표 제거 전에 다른 대상을 쫓지 않는다.
- 화력 행동: 후속 진입과 누킹을 같은 대상에 사용하고 첫 대상이 살아 있는 동안 타깃을 나누지 않는다.
- 전환 조건: 첫 제어가 실패하거나 한 명의 후속 진입이 닿지 않으면 나머지 핵심기를 보존한다.
- 망하는 패턴: 세 명이 비슷한 시간에 들어가는 것이 아니라 한 명씩 순차적으로 진입한다.

### 이중 전열 + 지속전 화력

- 승리 조건: 두 전열이 번갈아 상대 시선과 주요 스킬을 받고 후열의 공격 시간을 누적한다.
- 시작 방식: 첫 전열이 가까운 위협을 붙잡고, 두 번째 전열은 상대 후속 진입 또는 첫 전열의 생존기 종료에 맞춰 개입한다.
- 첫 타깃: 후열 화력이 끊기지 않고 닿는 가장 가까운 대상.
- 전열 행동: 둘이 동시에 생존기·제어기를 사용하지 않고 한 명이 빠질 때 다른 한 명이 선을 유지한다.
- 화력 행동: 전열이 바뀌어도 타깃을 불필요하게 바꾸지 않고 접근 가능한 적에게 지속 피해를 누적한다.
- 전환 조건: 후열과 전열의 거리가 벌어지면 추격보다 합류를 우선한다.
- 망하는 패턴: 두 전열이 함께 적 후열을 쫓아 후열 딜러가 진입자에게 노출된다.

### 탱커가 없는 3근딜·분산 화력

- 승리 조건: 세 명이 한 지역을 압축해 수적 우위를 만들고 서로의 근접 사거리 안에서 싸운다.
- 시작 방식: 둘 이상이 동시에 닿을 수 있는 목표와 각이 생겼을 때 진입한다.
- 첫 타깃: 가장 가치가 높아 보이는 적이 아니라 세 명이 동시에 때릴 수 있는 고립 대상.
- 전열 행동: 각자 다른 적의 시선을 끄는 것이 아니라 퇴로와 보호 범위를 함께 좁힌다.
- 화력 행동: 첫 대상 제거 전에는 별도 추격전을 만들지 않는다.
- 전환 조건: 한 명이 밀려나거나 진입각이 끊기면 남은 둘도 더 깊게 들어가지 않는다.
- 망하는 패턴: 세 명이 서로 다른 목표와 1대1을 시작한다.

### 2원딜·전열 부족

- 승리 조건: 한 명이 오래 맞는 전면전을 피하고 두 딜러의 사거리와 이동기를 번갈아 사용한다.
- 시작 방식: 한 딜러가 견제하는 동안 다른 딜러는 상대 진입에 대응할 이동기·제어를 남긴다.
- 첫 타깃: 뒤쪽 적을 억지로 찾기보다 먼저 이동기를 쓰고 들어온 가장 가까운 적.
- 화력 행동: 두 딜러가 서로 다른 방향으로 도망치며 화력을 나누지 않고 같은 진입자를 처리한다.
- 전환 조건: 첫 딜러의 이탈기가 빠지면 다른 딜러가 앞으로 나가 위협을 이어받는다.
- 망하는 패턴: 둘이 동시에 이동기를 공격적으로 사용해 상대의 다음 진입 턴을 막지 못한다.

## 구현 원칙

1. 고정된 `조합 유형 → 문장 세트` 매핑을 사용하지 않는다.
2. 실험체·무기별 특성에서 여섯 축을 계산한 뒤 각 축의 우선순위를 합성한다.
3. 상충하는 규칙은 핵심 화력의 생존과 실제 화력 도달 가능성을 기준으로 해결한다.
4. `적 원딜을 문다`, `무조건 받아친다` 같은 무조건 표현을 사용하지 않는다.
5. 실제 상대 조합·지형·스킬 이벤트가 없으므로 타깃과 전환은 상태 기반 조건으로 표현한다.
6. 사용자 리플레이 제보가 들어오면 조합 이름보다 `첫 타깃 상태`, `화력이 갈린 시점`, `전열·후열 분리 여부`를 기록한다.

## 기존 모델과의 관계

2026-08-09에 기존 `구도 설계 7종`과 고정 5단계 타임라인을 핵심 출력에서 제거했다. 분석 데이터에는 여섯 특성 축과 일곱 교전 원칙을 유지하지만 카드 UI에는 반복을 줄이기 위해 `화력 방식`, `접근 방식`, `전열 구조`와 `승리 조건`, `싸움 시작`, `망하는 패턴`만 표시한다. 조합 유형은 접힌 카드의 배지로만 식별하고, 펼친 영역에서는 같은 유형 설명과 역할·파워 스파이크·상성 요약을 다시 노출하지 않는다. 타깃·전열·화력·전환의 세부 판단은 실험체별 실행·금지 행동에 반영한다.
