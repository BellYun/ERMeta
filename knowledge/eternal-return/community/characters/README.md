# 실험체 특성·숙련 난이도 커뮤니티 지식

> 고조회수 실험체 분류 영상과 공개 시청자 의견을 바탕으로, 캐릭터의 강함과 별개인 **학습 비용·조작 부담·판단 부담**을 ERMeta 분석 축으로 정리한 문서다. 영상의 티어 배치를 현재 패치의 사실로 사용하지 않는다.

> **12.0 재검증:** 숙련 난이도 축은 유지하지만, 2026-08-06의 무기 스킬 개편으로 조작·판단 부담이 달라진 실험체가 있을 수 있다. 영상의 개별 배치는 현재 확정값으로 사용하지 않는다.

## 이 영상을 선택한 이유

검색 후보 중 이 영상은 조사 시점 조회수가 13만 회를 넘었고, 한두 실험체의 공략이나 패치 티어표가 아니라 여러 실험체를 **기본 조작을 익힌 뒤 성능을 내기까지 필요한 연습량**으로 분류한다.

작성자의 고정 댓글은 역할별 성능의 고점·저점 분류를 후속 영상에서 별도로 다루겠다고 설명한다. 따라서 이 자료를 “어떤 캐릭터가 강한가”가 아니라 “어떤 종류의 숙련을 얼마나 요구하는가”를 설명하는 자료로 제한한다.

## 영상에서 확인된 숙련 구간

영상은 실험체를 다음 다섯 구간으로 나눈다. 아래 구간명은 영상의 챕터를 요약한 것이며, 판수는 보편적인 보장값이 아니라 제작자의 경험적 분류다.

| 숙련 구간           | 의미                                                   | 근거                                                          |
| ------------------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| 기본 스킬·콤보 이해 | 스킬 구조와 기본 콤보를 알면 입문 성능을 내기 쉬운 군  | [1:25~](https://www.youtube.com/watch?v=MXuvl1FI3KY&t=85s)    |
| 수십 판             | 비교적 짧은 반복 플레이로 기본 성능이 안정되는 군      | [2:25~](https://www.youtube.com/watch?v=MXuvl1FI3KY&t=145s)   |
| 100~200판           | 메커니즘과 운용을 체화하는 데 더 긴 반복이 필요한 군   | [11:25~](https://www.youtube.com/watch?v=MXuvl1FI3KY&t=685s)  |
| 수백 판 이상        | 장기간의 캐릭터 전용 숙련이 필요한 군                  | [20:46~](https://www.youtube.com/watch?v=MXuvl1FI3KY&t=1246s) |
| 평생 수련           | 숙련 상한을 닫기 어렵다고 별도 취급한 최상위 학습 곡선 | [20:24~](https://www.youtube.com/watch?v=MXuvl1FI3KY&t=1224s) |

이 분류에서 중요한 값은 정확한 판수보다 **학습 곡선의 상대적인 길이**다. 같은 구간 안에서도 유저의 MOBA 경험, 주 역할군, 무기 숙련과 팀 조합에 따라 체감 난이도는 달라질 수 있다.

## ERMeta가 보존할 캐릭터 특성 축

> 아래 항목은 영상의 분류와 공개 댓글에서 반복된 설명을 ERMeta 관점으로 재구성한 `종합`이다. 원저자가 제공한 고정 데이터 스키마가 아니다.

| 특성 축                   | 분석할 질문                                                    | 강함과 분리해야 하는 이유                           |
| ------------------------- | -------------------------------------------------------------- | --------------------------------------------------- |
| `entryDifficulty`         | 스킬과 기본 콤보를 처음 익히기 어려운가?                       | 입문이 쉬워도 패치 성능이 낮을 수 있다.             |
| `practiceToBaseline`      | 안정적으로 기본 성능을 내기까지 어느 정도 반복이 필요한가?     | 영상의 다섯 숙련 구간을 직접 표현한다.              |
| `mechanicalLoad`          | 입력 속도, 조준, 콤보 순서와 동시 조작 부담이 큰가?            | 조작 부담은 승률과 동일한 개념이 아니다.            |
| `decisionLoad`            | 진입·이탈·스킬 배분을 상황에 맞게 바꿔야 하는가?               | 손이 쉬운 실험체도 판단 부담은 높을 수 있다.        |
| `positioningLoad`         | 전열·중열·후열 중 맡아야 할 위치가 조합과 교전마다 달라지는가? | 같은 캐릭터도 조합에 따라 난이도가 달라진다.        |
| `visionTerrainDependence` | 암시야와 지형 활용이 성능 발휘에 얼마나 중요한가?              | 캐릭터 조작만으로 설명되지 않는 맵 숙련을 분리한다. |
| `matchupKnowledgeLoad`    | 상대 실험체의 빈틈과 교전 가능 구간을 얼마나 알아야 하는가?    | 게임 지식 부족을 캐릭터 약세로 오해하지 않게 한다.  |
| `errorPunishment`         | 진입이나 스킬 한 번의 실수가 생존 실패로 이어지기 쉬운가?      | 같은 난이도라도 실패 비용은 다를 수 있다.           |
| `masteryCeiling`          | 기본 성능 이후에도 추가 숙련으로 개선할 여지가 큰가?           | 입문 난이도와 고점 숙련도는 서로 다른 축이다.       |

## 공개 댓글에서 수집한 보완 사례

다음은 영상 아래 공개 댓글을 익명으로 요약한 **사용자 제공 정보**다. 개인의 경험담이므로 캐릭터의 확정 특성이나 티어로 사용하지 않고 `검증 필요` 상태로 둔다.

| 실험체           | 사용자 의견의 요지                                                                 | 파생 특성 후보                              | 상태      |
| ---------------- | ---------------------------------------------------------------------------------- | ------------------------------------------- | --------- |
| 마르티나         | 조작 자체보다 암시야·지형 활용과 촬영 동선 판단이 어렵다는 의견                    | `visionTerrainDependence`, `decisionLoad`   | 검증 필요 |
| 클로에           | 상황 판단과 진입 선택이 중요하고, 진입 뒤 이탈 여지가 작아 실수 비용이 크다는 의견 | `decisionLoad`, `errorPunishment`           | 검증 필요 |
| 쇼이치           | 빠르고 정밀한 연속 조작 요구가 특히 높다는 의견                                    | `mechanicalLoad`                            | 검증 필요 |
| 카밀로           | 기본 성능 도달과 고점 발휘에 필요한 판수가 크게 다르다는 의견                      | `practiceToBaseline`, `masteryCeiling` 분리 | 검증 필요 |
| 엠마             | 조합과 상황에 따라 전열·중열·후열 역할이 바뀌어 위치 판단이 어렵다는 의견          | `positioningLoad`, `decisionLoad`           | 검증 필요 |
| 얀·아디나·알렉스 | 수백 판보다 더 긴 전용 숙련이 필요하다는 의견                                      | `masteryCeiling`                            | 검증 필요 |

댓글의 좋아요 수는 의견의 진위를 증명하지 않는다. 이 사례들은 향후 다수 출처와 실제 통계로 검증할 **태그 후보**로만 사용한다.

## 데이터 분석에 연결하기

실험체·무기별 학습 프로필을 만든다면 다음과 같이 버전이 있는 파생 데이터로 관리한다.

```yaml
character_learning_profile:
  character_code: 0
  weapon_type: "weapon-code"
  patch_version: "season.patch"
  classification_version: "community-v1"
  entry_difficulty: "low | medium | high | unknown"
  practice_to_baseline: "basic | tens | 100-200 | hundreds+ | lifelong | unknown"
  mechanical_load: "low | medium | high | unknown"
  decision_load: "low | medium | high | unknown"
  positioning_load: "low | medium | high | unknown"
  vision_terrain_dependence: "low | medium | high | unknown"
  matchup_knowledge_load: "low | medium | high | unknown"
  error_punishment: "low | medium | high | unknown"
  mastery_ceiling: "low | medium | high | unknown"
  evidence_status: "confirmed | synthesized | needs-validation"
```

이 값들은 공식 Open API가 직접 제공하는 필드가 아니다. 실험체와 무기, 패치, 분류 버전, 출처를 함께 저장해야 한다.

### 검증 가설

1. `practiceToBaseline`이 긴 실험체는 저숙련 표본과 고숙련 표본의 성과 차이가 더 클 수 있다.
2. `masteryCeiling`이 높은 실험체는 전체 평균보다 상위 티어·전문 유저 표본에서 성과가 더 좋아질 수 있다.
3. `positioningLoad`와 `decisionLoad`가 높은 실험체는 조합 구조에 따른 성과 분산이 더 클 수 있다.
4. `errorPunishment`가 높은 실험체는 평균 순위보다 교전 실패 시 하위 순위 비중이 두드러질 수 있다.

위 문장은 분석 가설이며 영상이 입증한 결과가 아니다. 유저별 숙련 판수를 직접 알 수 없는 현재 데이터에서는 티어, 반복 닉네임, 픽 집중도 등을 대리 변수로 쓰더라도 한계를 명시한다.

## 사용 금지 규칙

- 숙련 난이도가 높다는 이유만으로 강캐 또는 약캐라고 쓰지 않는다.
- 영상의 판수 구간을 모든 유저에게 적용되는 절대 기준으로 표시하지 않는다.
- 2025년 10월의 캐릭터 배치를 현재 패치 추천에 그대로 재사용하지 않는다.
- 공개 댓글 한 건을 실험체의 확정 특성으로 승격하지 않는다.
- 무기군과 빌드가 다른 동일 실험체를 무조건 하나의 난이도로 합치지 않는다.

## 패치 의존성과 갱신 조건

- 스킬 구조, 무기군, 이동기 또는 핵심 콤보가 리워크되면 해당 실험체 분류 재검증
- 신규 실험체가 추가되면 동일 기준으로 별도 평가하되 기존 구간의 의미는 유지
- 같은 주제의 최신 고조회수 자료가 나오면 조회수보다 분류 기준과 패치 적합성을 우선 비교
- 사용자 제보가 누적되면 서로 일치하는 경험과 충돌하는 경험을 함께 보존
