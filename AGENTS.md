# Repository agent instructions

- Create pull requests ready for review by default. Do not create draft pull requests unless the user explicitly asks for a draft.
- Follow `.github/pull_request_template.md` for pull request descriptions. Use a Korean summary after the conventional commit prefix in the title, consistent with recent pull requests.
- Write commit subjects as `<type>: <Korean summary>`, following recent repository history. Include an issue reference only when there is a relevant issue.
